# Garage 3D Implementation Plan

> **For agentic workers:** Use the agreed independent model, cosmetics and renderer surfaces, followed by integration review.

**Goal:** Show each store's saved bot in the approved realistic 3D style inside the Garage.

**Architecture:** A lazy scene consumes the existing authorized `BotLookProps`; the main Garage editor remains the source of draft appearance. Separate bot geometry, cosmetics, camera framing and React lifecycle modules.

**Tech Stack:** React, TypeScript, Three.js 0.170.0.

**Spec:** `docs/superpowers/specs/2026-10-29-garage-3d-design.md`

## Constraints and review focus

Garage only. No gameplay or persistence mutations from rendering. Verify hidden loadouts, crew proposals, all equipment families, tall accessories on narrow screens, repeated appearance changes and 2D fallback.

## Validation recorded

- 95 targeted tests passed, including the 12 new geometry, catalogue, accessory framing, visibility and immutability checks and existing gameplay, persistence and repair regressions.
- Typecheck, focused ESLint and the production build passed. No database migration ran; browser testing used isolated local data.
- Inspected development and locally built previews at desktop and 390px phone widths. Full bots and tall heart flags fit; no horizontal page overflow.
- Exercised appearance changes, saving/reloading, rotation, reset, zoom and the manual 2D fallback. The locally built preview reported no browser console warnings or errors.
- The viewer consumes the existing composed draft appearance. No new database write, unlock calculation or battle-stat calculation was introduced.
- Part tiers reuse their family geometry; this is a visual upgrade, with gameplay effects still supplied by the existing backend. Automated WebGL failure handling was reviewed but a forced GPU loss was not part of browser testing.
- The user authorized production release on 2026-10-29. Release `codex/garage-3d` through the existing GitHub/Vercel pipeline after its checks pass, then verify the custom production domain.
